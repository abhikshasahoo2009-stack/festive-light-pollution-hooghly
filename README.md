# festive-light-pollution-hooghly
Did a 2-week spatial photometric survey across 6 festive sites in Hooghly, West Bengal. Engineered a Java pipeline with moving-average filters to process sensor logs. Discovered a 26-fold spike in commercial glare. Modeled dry-eye &amp; pediatric circadian risks from 450nm light. Designed sub-150 INR open-science retrofits.
